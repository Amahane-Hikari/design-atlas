# Design Atlas 4.2 · 前端设计工作室

一个可以在浏览器里探索设计、调整主题、拼装页面并带走源代码的工作台。核心交互不依赖外部 CDN，也不需要账号或后端。

在线使用：[Design Atlas](https://design-atlas-gold.vercel.app/) · 源码仓库：[luomo66ccff/design-atlas](https://github.com/luomo66ccff/design-atlas)。

## v4.2：画布手感与细节打磨

- **编辑控件不随画布缩小**：选中框、模块名称、工具条、间距手柄、元素拖动手柄、参考线和放置线会按画布缩放反向放大。画布缩到 58% 时，工具条按钮在屏幕上仍是 30×28px，元素手柄仍是 12px；改缩放或切换设备时立即生效，无需重新载入画布。
- **工具条不再挡住内容**：上方空间足够时放在模块上方；顶部导航这类矮模块放到模块下方；只有又高又贴顶的模块才放进模块内。模块名称标签同理。
- **资源库卡片整张可点**：点描述文字也能打开预览，收藏按钮照常工作；选中文字时不会误触打开。
- 排序下拉只保留一个箭头；案例页的统计数字改用与资源库一致的衬线数字；手机上可横向滚动的标签栏右侧加了渐隐提示。

## v4.1：智能参考线、手机端单独调整与元素样式剪贴板

- **智能参考线**：拖动元素时，它的左右边、上下边和中线会自动吸附到所在模块、父级容器和相邻元素的对应位置，并显示粉色参考线；按住 Alt 拖动可关闭吸附。
- **手机端单独调整**：把画布切到手机宽度（≤ 760px）后，对元素的拖动和检查器修改只作用于手机，桌面版保持不变；检查器会提示「手机端单独调整」，「清除手机调整」一键恢复跟随桌面。
- **元素样式剪贴板**：选中元素后「复制元素样式」（Ctrl+C），再选另一个元素「粘贴」（Ctrl+V），颜色、字号、背景、圆角、阴影等外观一并套用，位置保持不动。
- 画布手柄设置了 `touch-action:none`，在触屏上拖动元素不会误滚动页面。

## v4：「制图室」视觉重构与任意元素自由编辑

- **全新视觉「制图室 · Cartographer」**：暖调纸张底色、石墨墨色侧栏、唯一的朱砂红信号色；衬线大标题配等宽「坐标」小字，细线分隔、网格纸卡片、等高线装饰与极淡纸纹。深色模式同步重做。新样式集中在 `dist/atlas.css`，原有 520 个颜色变量按角色重新映射（`scripts/tokenize-colors.mjs` 的 `paletteMap`），未单独重写的旧组件也会自动融入新配色。
- **任意元素自由编辑**：在画布中选中模块后，再点其中任何元素（标题、段落、按钮、图片、卡片、容器……）即可：
  - 直接拖动移位（Shift 锁定方向，接近原位自动吸附），右侧手柄改宽度，右下角缩放，顶部圆点旋转（Shift 吸附 15°）；
  - 方向键微调 1px、Shift+方向键 10px，Delete 隐藏元素，Esc 选择父级；
  - 在「元素」面板精确设置 X / Y、旋转、缩放、宽度、不透明度、层级，文字颜色、字号、字重、对齐、行高、字距、斜体、大写，背景、圆角、内边距、边框、阴影、模糊与可见性。
  所有修改都写入 `block.style.free`，导出为作用于该模块的 CSS，可撤销。

## v3.1：元素级编辑、图片素材与深色模式

- **元素级编辑**：在画布上先点选模块，再点其中的上方短句、主标题、说明文字或按钮，就进入「元素」面板，可单独调颜色、字号、字重、对齐、字距、斜体、大写，或隐藏这个元素。双击仍然是原地改字。
- **拖边调间距**：选中模块后，上下边缘出现蓝色手柄，按住拖动即可实时调整上边距和下边距，松手后可撤销。画布中按 ↑ / ↓ 在模块间切换选择，工具条新增「＋」直接在下方加模块。
- **图片与素材**：新的「素材」面板支持拖入或选择 PNG / JPG / WebP / GIF，浏览器内自动压缩到 1600px 并转 WebP，最多 24 张。把素材拖到画布里的图片位就替换那张图，拖到模块其他位置则设为模块背景；也可从桌面直接把文件拖进画布。模块背景图可调填充、焦点、遮罩强度与颜色、模糊。37 处图片位覆盖首屏、作品、商品、头像、封面等。
- **更自由的配色**：区块渐变支持线性 / 径向 / 锥形、角度和第三种颜色。
- **更多特效**：入场新增斜切、翻页、弹出（共 15 种）；悬停新增磁吸、按压、光斑跟随（共 9 种）；标题新增解码、波浪、霓虹闪烁、描边填色（共 11 种）；背景新增流体色块、复古网格、流动渐变（共 15 种）；新增 6 种**滚动特效**（视差、渐隐渐现、缩放推进、上浮跟随、透视倾斜、景深模糊）；光标新增星光拖尾。
- **17 个新组件、6 套新模板**：全幅图片首屏、图文分栏、瀑布流图集（点击放大）、图片 Bento、图片跑马灯、商品网格（演示购物袋）、环形指标、趋势卡片、垂直时间轴、编号步骤、悬停揭示卡、轮换词标题、视差层叠首屏、联系信息卡、社交链接、图片引言、视频展示；模板含摄影作品集、生活方式小店、动态创意工作室、数据分析产品、个人链接主页、旅行手记。共 81 个组件、24 套模板。
- **外壳深色模式**：顶栏新增浅色 / 深色切换，默认跟随系统。全部外壳颜色收敛为设计变量（`dist/tokens.css`，由 `scripts/tokenize-colors.mjs` 生成，深色值按 OKLab 亮度映射计算）；页面切换淡入、主题化滚动条。
- **撤销更省内存**：历史记录只保存图片 ID，图片数据共用一份，撤销删除图片也能恢复。

## v3：可视化工作室与特效系统

- **重做的拼装台**：进入「页面拼装台」后侧栏收为图标栏，左侧「图层 / 组件 / 模板」，中间是真实宽度的画布，右侧「内容 / 样式 / 动效 / 页面」检查器。
- **在画布上直接操作**：单击选中模块（悬停显示名称），选中后出现浮动工具条：拖动 ⋮⋮ 排序、上移、下移、复制、重播动效、隐藏、删除。双击标题、按钮、列表项等文字即可原地修改，Enter 确认、Esc 取消。
- **拖进来**：从「组件」面板把卡片拖到画布任意位置，蓝色指示线标出落点；点击卡片则加入选中模块下方。图层列表支持鼠标、触控笔与触屏的拖动排序，双击图层名可重命名。
- **快捷键**：Delete 删除，Ctrl/⌘+D 复制，Ctrl/⌘+C / V 复制粘贴模块，Alt+↑/↓ 移动，Ctrl/⌘+E 切换编辑/交互预览，Ctrl/⌘+Z 撤销。连续输入或拖动滑块会合并为一步撤销。
- **画布**：自适应、桌面 1440、笔记本 1280、平板 820、手机 390 五种宽度，可缩放到适应窗口或 50%–125%。修改文字和样式时只局部刷新对应模块，结构变化用双缓冲画布切换，不再闪白或跳回顶部。「交互预览」按导出效果运行按钮、表单、动效与光标。
- **每个模块的样式**：色调（柔和/反转/强调色/深色/纯白）、自定义底色与渐变、本区强调色、12 种背景特效（网格、圆点、斜纹、颗粒、渐变、极光、流体、跟随光斑、星点、光束、同心圆、波浪）及强度、宽度、对齐、上下边距、圆角、内容缩放、顶部形状、吸顶/毛玻璃吸顶、按设备隐藏，以及只作用于本模块的 CSS（支持 `&`）。样式可复制粘贴到其他模块。
- **动效**：12 种入场（淡入、上浮、下落、左右滑入、放大、缩小、模糊聚焦、翻转、旋入、幕布揭示、弹跳），可调触发时机、子元素依次出现、时长、延迟与节奏；6 种悬停（上浮、光晕、3D 倾斜、放大、流光扫过、描边）；7 种标题特效（渐变、流光、荧光笔、空心描边、下划线、辉光、逐字出现）；3 种循环动效。全部尊重系统的「减少动态效果」设置。
- **页面级**：16 套主题（新增落日奶油、午夜极光、薄荷苏打、纸本黑白、樱花信笺、赛博霓虹、大地陶土、冰川玻璃），6 种颜色、9 种系统字体（正文/标题可分开）、标题字重与字号比例、6 种质感（含玻璃拟态、线框、悬浮立体）；滚动进度条、回到顶部、胶片颗粒、主题滚动条、3 种光标效果、3 种开场动画、默认入场动效。
- **22 个新组件、8 套新整页模板**：渐变大字/玻璃拟态/终端/3D 叠卡首屏，标志墙、滚动计数、团队、前后对比滑块、手风琴、评价轮播、交错功能、滚动叠卡、3D 倾斜卡片、对话界面、日程预约、文章卡片、流光边框 CTA、大字页脚、倒计时、音乐播放卡、滚动点亮文字、环绕集成图；模板含 AI 产品发布、大胆创意代理、开发者工具、线上发布会、杂志博客、玻璃拟态应用、音乐人主页、身心健康品牌。
- **特效实验室**：新页面集中预览全部入场、悬停、标题、背景与循环效果，一键应用到当前选中的模块或开启页面特效。
- **兼容**：项目仍是 `version:1`，新增的 `block.style`、`block.label` 与 `effects` 都是可选字段，旧项目、扩展包与配方照常打开；导出页面只包含运行所需的特效脚本，不含编辑器代码。

## Vercel 部署

在 Vercel 导入此 GitHub 仓库即可。根目录的 `vercel.json` 已指定静态输出目录 `dist`，构建会依次执行模块检查、案例与导入检查，再生成离线单文件。项目没有 npm 运行时依赖，也不需要环境变量。

Git 集成连接后，推送默认分支会触发线上更新；其他分支可生成预览。网站数据存储在访问者自己的浏览器，部署更新不会同步不同设备里的个人项目。使用「保存项目」和扩展包导出备份或迁移。

## v2.1：从灵感库到创作工作台

- **全局搜索**：点击顶栏或按 Ctrl / ⌘ K，跨网站案例、模块、模板、设计参考、源码资源、技能、主题和已存项目查找。支持分类、多个关键词、方向键和 Enter；默认显示常用操作与最近保存的方案。
- **我的项目**：将当前草稿存为独立方案，最多 24 份。可搜索、打开、复制、重命名、下载或移除；最近一次库修改可撤销。打开方案可以撤销回上一个草稿。方案是手动保存的副本，不随草稿自动更新。
- **项目库迁移**：整库 JSON 导入导出，最多 6 MiB；相同 ID、不同内容的冲突会拒绝整个导入。保存使用浏览器 Web Locks 协调标签页，过期标签页不会覆盖新保存的数据；不支持此能力的浏览器保留 JSON 下载方式。
- **更换布局**：在拼装台选中模块，从「试试另一种布局」选择同类模块；保留同名文案字段、图层位置与隐藏状态，缺少的字段使用新布局默认值。可以一步撤销。
- **源码分屏**：HTML / CSS / JS / 项目 JSON 与隔离预览同屏显示；600ms 延迟自动更新，可关闭自动更新，或用 Ctrl / ⌘ Enter 手动运行。支持不同预览宽度；JSON 无效时保留上一次有效预览。Tab 正常切换焦点。
- **阅读体验**：提高说明文字与控件对比度，新增项目卡片、空状态和窄屏布局。

借鉴来源与实际采用的设计决策见 [DESIGN_RESEARCH.md](DESIGN_RESEARCH.md)。原有案例、配方、导出和旧项目 JSON 保持可用。

## 打开方式

- **直接双击 `dist/offline.html`**：完整的离线单文件，包含界面、组件与资源目录；无需 Node.js。
- **双击 `启动工作台.cmd`**：已安装 Node.js 时运行本地服务器，访问 `http://127.0.0.1:4317`；没有 Node.js 时自动打开离线版。
- 开发时执行 `npm start` 或 `node scripts/serve.mjs`。服务器仅监听 `127.0.0.1`。
- `dist/index.html` 使用 ES modules 和 JSON 文件，请通过 HTTP 打开。不要直接双击此文件；离线使用请选择 `offline.html`。

卡片是**原创布局示意**，详情中的 iframe 是**原创适配预览**；点击「访问原站」查看真实网站。配方与主题是适配建议，不是原站测量结果或源码复制。没有打包原站品牌素材。

## 能做什么

1. 在设计库里按类型、分类、关键词筛选，切换网格/列表，收藏喜欢的条目。
2. 打开原创模块，修改标题、文案、颜色、字体、圆角和章节间距；切换桌面、平板与手机宽度。
3. 将模块拖进画布或加入页面，组合不同类别；在画布或图层里拖动排序，双击文字原地修改。支持复制、隐藏、删除、复制粘贴样式、撤销与重做。
4. 套用整页模板或新建空白画布，用检查器修改各个模块，并添加自定义 CSS。
5. 复制完整 HTML、HTML 片段、CSS、JavaScript 或项目 JSON；完整 HTML 可直接保存为 `.html` 运行。片段需要与对应 CSS、JS 一起使用。
6. 在源码编辑器修改完整 HTML 或各代码片段，点击「试运行修改」，在隔离预览里检查结果，然后复制或下载。
7. 项目自动保存在当前浏览器；使用「保存项目」下载 JSON，之后可重新导入继续拼装。导入会校验模块类型、颜色与容量限制，失败时保留当前页面。
8. 在参考详情中复制配色，或将提取的配色应用到原创模块；在技能详情复制可直接使用的任务提示。

## 自己扩充

```powershell
# 重新扫描本地技能和 DESIGN.md；不联网、不改原始文件
node scripts/refresh-local-catalog.mjs

# 指定自己的技能目录（可重复传参；指定后替换默认扫描根）
node scripts/refresh-local-catalog.mjs --skills-root D:\my-skills

# 只检查、不写入
node scripts/refresh-local-catalog.mjs --dry-run

# 生成包含最新界面和目录的离线单文件
node scripts/build-offline.mjs

# 检查模块输出、项目往返、导入边界与数据完整性
node scripts/check.mjs
```

开源资源存放在 `dist/data/catalog.json` 的 `resources`；本地参考位于 `dist/data/local-references.json`。刷新会保留已有的 resources 和人工维护的中文摘要。新增模块在 `dist/pattern-engine.js` 注册，案例协议与配方位于 `dist/case-model.js`；新增主题修改 engine 的 THEMES。详情见 EXTENDING.md。修改后重建离线版。

工程使用原生 ES modules，无 npm 运行时依赖。`npm start` 只调用内置 Node HTTP 服务器。将 `dist/` 作为静态目录即可部署。
